# StickerVox v1 — sound stickers from video for WhatsApp Web

Objective: a Chrome/Chromium MV3 extension, written from scratch (no code from "Stickers Sounds" / WA-audio-stickers), that turns a video clip into an animated sound sticker with free framing, synced captions and normalized audio, and sends it from WhatsApp Web.
Branch: `feat/stickervox-v1` · Delivery strategy: `ask-on-risk` · Test runner: `node --test` (Node 24) for pure modules; browser checks in ego-browser.

## Specs

- **S1 — Clean-room origin.** User: "crea el código desde 0 para no estar atado a la licencia de ellos". No file, function or code fragment may be copied from the `stickers-sounds` extension. Facts about WhatsApp Web internals (module names, object shapes) are interoperability knowledge and may be used. Icons and UI art must be original (no third-party characters).
- **S2 — Free framing ("encuadre libre").** The user picks a square region of the video by dragging and zooming over a preview, instead of only center-crop/fit. The chosen region is what the sticker shows.
- **S3 — Synced captions ("texto sincronizado").** The user adds one or more text cues, each with text, start time, end time and position (bottom or top). Default style: bold white text with black outline (Impact-like). Cues render only between their start and end times.
- **S4 — Normalized audio ("audio normalizado").** The clip audio is peak-normalized (target about −1 dBFS, no clipping) with an option to turn it off; fades of ~40 ms at both ends avoid clicks.
- **S5 — Trim.** The user selects the start/end of the clip; the maximum duration is a single constant: 15 s (raised from 5 s per L10, after a live test where 10 s and 15 s sound stickers were delivered and played in full on the user's phone). Longer clips lower fps/quality to fit the 500 KB WebP budget; clips with heavy motion may not fit and get a clear error.
- **S6 — Output formats.** Sticker: animated WebP, 512×512, under a size budget constant (1000 KB since L14; WhatsApp Web accepted 1023 KB and rejected 1520 KB), quality/fps reduced automatically to fit. Audio: Ogg/Opus (`audio/ogg; codecs=opus`), which WhatsApp's `WAWebSoundStickerUtils.isSoundStickerAudioMimetype` accepts.
- **S7 — Send.** The user searches and picks a chat or group, previews the result with audio, and sends. The extension uploads the audio through WhatsApp Web's media upload and attaches it as `stickerAudio` when sending the sticker. It must not force WhatsApp feature gates (`WAWebABProps`) — in the user's account the sound-sticker gates are already on.
- **S8 — Privacy.** No network requests other than WhatsApp Web's own; nothing is sent anywhere except the sticker the user explicitly sends to the chat they picked.

Non-goals for v1: downloading from YouTube (blocked in-browser; stays an external `yt-dlp` step), transcription-based phrase search, mobile browsers, Firefox/Safari.
